# e-plantShopping

A responsive e-commerce web application that brings the plant nursery experience directly to digital devices. This platform allows users to browse, search, and securely purchase indoor plants, succulents, and gardening supplies.

## 🌟 Features

* **Dynamic Catalog:** Browse plants filtered by categories like Air Purifying, Insect Repellent, and Aromatic.
* **Interactive Cart:** Add items, update quantities, and see real-time price calculations.
* **Responsive Design:** Optimized for seamless viewing on mobile, tablet, and desktop screens.
* **Fast Navigation:** Built as a Single Page Application (SPA) for instant page transitions.

## 🛠️ Tech Stack

* **Frontend:** React, Vite, HTML5, CSS3, JavaScript (ES6+)
* **State Management:** Redux Toolkit

## 🚀 Getting Started

### Prerequisites

* Node.js (v16.0.0 or higher)
* npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```

2. Navigate to the project directory:
   ```bash
   cd e-plantShopping
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

### Running the Application

1. Start the local development server:
   ```bash
   npm run dev
   ```

2. Open your browser and navigate to the local URL provided in your terminal (usually `http://localhost:5173`).
